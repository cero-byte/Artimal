# 3D model files

The GLB models are not stored in Git because of their size.

模型文件因体积较大，不保存在 Git 仓库中。

Download the six models and place them here with these exact names:

请下载六个模型，并使用以下准确文件名放在本目录：

```text
brain.glb
face.glb
heart.glb
limbs.glb
lungs.glb
stomach.glb
```

Required format: glTF 2.0 Binary (`.glb`).

要求格式：glTF 2.0 Binary（`.glb`）。

See [`README.md`](../../README.md) for download links and installation instructions.

下载链接和安装步骤见 [`README.md`](../../README.md)。
